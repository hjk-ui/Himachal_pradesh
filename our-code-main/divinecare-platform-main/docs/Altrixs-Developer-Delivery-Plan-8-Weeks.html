7. Definition of Done (har feature)

  • API org-scoped + wrong-org → 403/404
  • UI role ke hisaab se accessible (roleAccess)
  • Mocks/DEMO removed for that screen
  • npm run typecheck pass
  • Happy path + unauthorized path manually tested
  • Seed/data for local demo updated if needed

8. Local setup (dev quick)

cp .env.example .env → DATABASE_URL, AUTH_SECRET, AUTH_URL=http://localhost:3000
npx prisma db push && npm run db:seed
Platform admin: npm run db:create-platform-admin
npm run dev → clinic: admin@altrixs.local / Altrixs@123

9. Risk & notes for developers

  • Don’t call missing APIs when DATABASE_URL set — alerts/messages pehle se mock-gated rakhe hain until Week 3.
  • lib → features import forbidden — shared types src/types/* mein.
  • Browser fetch = apiJson from lib/api-client.ts.
  • Community/PR low priority — Week 8 buffer mein hi touch karo.
  • Telehealth video vendor (Daily/Twilio) integration Week 7 mein stub-first OK.
