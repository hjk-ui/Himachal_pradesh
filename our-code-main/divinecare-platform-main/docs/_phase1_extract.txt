1 Live clinic ke liye keys (.env)
SIMPLE MATLAB
App ko batana hai: database kahan hai, login secret kya hai, email kaise bhejna, Zoom ka account, insurance check
(Availity), clinic ka monthly Stripe plan.
KYA KARNA HAI
DATABASE_URL, AUTH_SECRET, AUTH_URL = jo URL browser me khulegi (local pe http://localhost:3000, live pe
https://altrixs.com).
SMTP — staff invite aur password OTP.
Zoom: account id, client id/secret, host email. Example file: .env.example.
Passwords / secrets git pe commit mat karo.
TEST
Login chale. Invite email inbox me aaye.
Keys missing hon to page crash na kare — samajh aaye wala error.
Galat AUTH_URL pe login loop / cookie tootna nahi chahiye (local vs live mix mat karo).
2 Zoom telehealth (staff + client browser)
SIMPLE MATLAB
Doctor video call Zoom se kare. Client phone pe app nahi — link browser me khole. Call khatam = appointment
complete.
MAT KARNA
AWS Chime, mobile app join button, recording S3, Transcribe Medical.
TEST
1. Front desk Virtual appointment banaye.
2. Therapist Start/Join → Zoom meeting khule (host).
3. Incognito window me join link — bina staff login ke client join ho.
4. End session → appointment status Completed.
5. Doosri clinic ka join token kaam na kare.

3 Appointment confirm — email / SMS (bina app)
SIMPLE MATLAB
Appointment save hote hi client ko yaad: kab aana hai, kaunsa clinician. Clinical baat message me nahi.
KYA KARNA HAI
Pehle email theek se bhejo. SMS tab jab clinic Twilio/Pinpoint de.
Virtual visit pe Zoom join link alag se (email/SMS), diagnosis nahi.
Phone/email empty ho to save se pehle error dikhao — silent fail nahi.
TEST
Naya appointment → inbox me text padho: sirf date/time/name.
Fake diagnosis SMS me leak to nahi (code review + ek real send).
4
 Book pe Pay Now vs Pay at clinic (optional)
SIMPLE MATLAB
Front desk book karte time poochhe: abhi card se ya clinic aake pay. Yeh visit ka paisa hai. Altrixs ka monthly clinic
subscription Stripe alag cheez hai — mat milaana.
TEST (JAB LEAD BOLE BANANA HAI)
Pay at clinic → appointment Due at clinic.
Pay Now Stripe test card → Paid.
Billing role ko list dikhe.
Lead bole “abhi nahi” to yeh ticket skip.
5 Client papers / photos upload
SIMPLE MATLAB

TEST

Clinic B ka user Clinic A ki file na dekhe.

 Insurance eligibility (Availity)

8
 Claims — pehle draft sahi
SIMPLE MATLAB
Paisa insurance se maangne se pehle note signed + locked hona chahiye. Clearinghouse (asli submit) alag bada kaam

9 Progress notes polish
SIMPLE MATLAB
Doctor type kare to draft save hota rahe. Sign ke baad original note badalna illegal — addendum alag. Purani session
late likhi to “Late entry” dikhe.
TEST
Draft, thoda wait / refresh — text gaya nahi.
Signed note ka content PATCH → 403, DB me purana text.
Session 2 din purani + aaj sign → Late Entry header.

10 Risk alerts (bina patient app)
SIMPLE MATLAB
Client mood bahut kharab ya PHQ-9 last question (khud ko nuksan) 1+ → hamesha High alert. 1 ghante koi na dekhe
to director ko email/SMS: “A client alert needs attention” — naam/diagnosis nahi.
TEST
Check-in mood 2/10 → Alerts Unreviewed.
PHQ item 9 = 1, baaki 0 → phir bhi High (API me, sirf UI me nahi).
Review empty note se close ho sakta (product), audit me “no documentation” optional.
11 Safety plan + discharge (staff)
SIMPLE MATLAB
Crisis ke liye 6-step plan + ghar ko safe banana (means). Purana plan delete mat karo. Discharge ke 7 din aur 30 din
baad phone task clinician ke To-Do pe.
TEST
Plan save, list me; delete API fail.
Discharge sign → 7-day follow-up task due date theek.
Peer support clinical progress notes me na ghusey (alag module).
12 E-prescribe — abhi stub, jhoot mat bolo
SIMPLE MATLAB
Asli dawai pharmacy ko DrFirst se jaati hai. Woh contract ke bina custom form mat banao jo “sent to CVS” dikhe. Page
pe likho: pharmacy network pending. Sirf Psych/NP.
TEST
Therapist prescriptions URL → bounce /dashboard.
NP save → list me row (clinic JSON theek), “e-Rx transmitted” mat likho.
13 License expiry
SIMPLE MATLAB
Doctor ka license khatam → nayi billable appointment / claim mat jane do (lead confirm). Banner director ko.
TEST

Valid license → normal book.
